# Codex Workbench Monitor for ESP32-S3-RLCD-4.2

Adapted from [CEJXXX/token-monitor-RLCD](https://github.com/CEJXXX/token-monitor-RLCD).
The 400x300 dashboard shows Codex allowance, daily tokens, estimated focus
time, Beijing weather, AQI/PM2.5, conditional 3-hour rain risk, optional GitHub
PR/CI attention counts, and Bridge/Wi-Fi freshness.

See [README.md](README.md) for setup instructions.
