# Codex Token Monitor for ESP32-S3-RLCD-4.2

Adapted from [CEJXXX/token-monitor-RLCD](https://github.com/CEJXXX/token-monitor-RLCD).
It keeps the same Waveshare hardware and replaces the Claude/DeepSeek dashboard
with local Codex allowance data and Beijing weather.

See [README.md](README.md) for setup instructions. The dashboard shows Codex
allowance remaining and reset time, today's and latest-task token totals,
Open-Meteo current weather, onboard indoor temperature/humidity, time, and date.
